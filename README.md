# SkanEcom

Plateforme e-commerce multi-boutique « type Shopify » pour le marché tunisien. N'importe quelle entreprise, du vendeur Instagram à la marque établie, s'inscrit seule et met en ligne une boutique belle comme une grande marque, pensée pour le paiement à la livraison, et qui reste ouverte même quand nos serveurs tombent.

**État au 28/09/2026 : étape 0, cadrage.** Aucun code n'est écrit.

- Cadrage : [`docs/cadrage/`](docs/cadrage/README.md) — PRD, infrastructure, reprise de Maymar, décisions et risques.
- Client n°1 : Maymar (dépôt `saouthq/maymar`), dont le moteur (catalogue à variantes, cycle COD, stock) sera rendu multi-boutique.
